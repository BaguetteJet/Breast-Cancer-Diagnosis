## CS4106 Group Project Guide
Using Kaggle and Google Colab
For this project, each group will be assigned a dataset, a Kaggle baseline notebook, and a machine learning task. This is a small guided mini-project. Your job is to run the assigned baseline, make one improvement, compare the baseline with your improved version, explain what you changed and why, and submit your final notebook and short video.
### 1. What is Kaggle?
Kaggle is an online platform used for machine learning and data science. It is commonly used to find datasets, explore example notebooks, and compare results on shared problems. For this project, you will use Kaggle to access your assigned dataset and the baseline notebook for your task.
### 2. What is Google Colab?
Google Colab is an online notebook environment where you can write and run Python code in your browser. You do not need to install Python on your laptop to use it. Colab notebooks can be stored in Google Drive, shared with others, and uploaded from an existing .ipynb notebook file.
### 3. What will my group receive?
- a project title
- a Kaggle dataset link
- a Kaggle baseline notebook link
- a baseline model to start from
You must use the dataset assigned to your group.
### 4. What is a baseline?
A baseline is a simple starting solution. It is the first working model for the task. Your job is to understand it, run it, and then improve it. The baseline is not the final submission.
### 5. What is Kaggle used for in this project?
- open and read your assigned dataset
- download the dataset files
- open the assigned baseline notebook
- make a copy of the notebook if you want to experiment on Kaggle first
### 6. What is Colab used for in this project?
You will use Colab as your main coding space. It is where you can upload your dataset, run Python code, test ideas, and save your final notebook. Colab is useful for beginners because it works in the browser, but its runtime is temporary, so you should save your work regularly.
### 7. How do I download a dataset from Kaggle?
Open the dataset page assigned to your group and download the files to your computer. Keep the dataset files together in one folder so they are easy to upload into Colab later.
### 8. How do I use the baseline notebook on Kaggle?
Open the baseline notebook and read it carefully from top to bottom. Try to understand how the data is loaded, how the data is cleaned, what model is used, and how the model is evaluated. If you want to work on Kaggle first, use Copy & Edit to create your own editable version of the notebook.
### 9. How do I move from Kaggle to Colab?
You have two options.
Option A: Work on Kaggle first. Open the assigned notebook, use Copy & Edit, and try your changes there. If you want to continue in Colab, download the notebook asV an .ipynb file and upload it into Colab.
Option B: Work in Colab from the start. Open Colab, create a new notebook, and manually copy the parts of the baseline code that your group understands.
### 10. How do I upload data into Colab?
In Colab, use the Files panel on the left side and click Upload. Then choose the dataset file you downloaded from Kaggle.
### 11. How should I run the notebook?
Run the notebook one cell at a time. Do not run everything blindly. After each cell, check what the code is doing, what output it gives, and whether the result makes sense. This will help your group understand the project properly.
### 12. Can we copy code from Kaggle?
You may use the assigned Kaggle baseline notebook as your starting point. You may read it, run it, and copy parts of it into your own notebook. However, you must understand any code you use.

If the baseline is downloaded as a .py file, it is acceptable to run it as one script once you understand what it is doing.

If the baseline is downloaded as an .ipynb notebook, you should run it cell by cell so that you can follow the steps properly and understand the workflow.
A good way to show this clearly and honestly is to add a short comment such as:
```
# Starting point adapted from the assigned Kaggle baseline notebook
# Further changes made by our group
``` 
You may use the assigned baseline as your starting point, but your group must make its own improvement.
A simple improvement that your group understands is better than a complicated improvement that you cannot explain.
If your group makes a strong improvement, with a meaningful modification and a clear explanation of why the modification was made and how it improved the result, you can earn more marks.
### 13. What are we expected to improve?
Once the baseline works, your group must add one improvement. You only need to make one improvement. Your improvement can be made at any stage of the machine learning pipeline. For example, you might improve:
- preprocessing
- missing value handling
- feature selection
- feature scaling
- hyperparameters
- model choice
- evaluation
- error analysis
A clear, well-tested, and well-explained improvement can earn more marks.
### 14. What makes a good improvement?
A good improvement is one that is tested and clearly explained. You should explain what you changed, why you changed it, how you tested it, and whether it improved the result. One clear improvement is enough. A simple improvement that your group understands is better than a complicated improvement that you cannot explain.
### 15. What are we not allowed to do?
You must not:
- copy and paste improved code from other Kaggle notebooks
- combine several online notebooks and submit them as your own
- use code that your group cannot explain
- present other people’s work as your own improvement
You may start from the assigned baseline, but the improvement must come from your group.
### 16. What is the overall aim of the project?
The aim is not just to get the highest score. The aim is to show that your group can understand a baseline, make one clear improvement, compare the result before and after, and explain your work clearly.
### 17. What should be included in the video?
Each group must submit one short video. The video should be no longer than 5 minutes. It should explain the task, the dataset, the baseline, the improvement your group made, the final result, and what each member contributed. All group members should speak in the video. The video does not need to be highly edited or professional. Clear explanation matters more than presentation style.
### 18. What if our result is especially strong?
Some of these datasets already have public benchmark results on Kaggle, and some have related results reported in papers or public write-ups. If your group produces a strong and well-validated improvement over the assigned baseline, this may be rewarded with bonus marks.

6.	Run the baseline successfully

8.	Upload the dataset into Colab
9.	Build your own working notebook
10.	Test your improvement
11.	Compare your result with the baseline
12.	Explain what changed and why
13.	Prepare your final notebook and video
